[[https://antigravity.google][Google Antigravity]] (~agy~), as one of the editor's agents of
[[https://github.com/LispMachineLab/lispm-agent][LispM Agent]], beside Claude Code and Codex.  It
needs lispm-agent alone and works in any Emacs 30.1 or later;
[[https://github.com/LispMachineLab/lispm-desktop][LispM Desktop]]'s App Store installs it from its
AI Harness extensions.  In code, the prefix is ~lispm-antigravity-~.

* What it does

While ~agy~ is on ~PATH~, Antigravity takes part as Claude Code and Codex do:

- =y= in ~lispm-agents-map~ (=C-c a y= in LispM Desktop, where its agents sidebar and λ menu
  offer it too) starts Antigravity, in a terminal, at the current project's root.
- Its sessions join the others in ~lispm-agents-sessions~ (=C-c a s=), grouped by project, with
  subagent conversations nested under the session that spawned them, and resume where they ran
  with ~agy --conversation ID~.  They are read from Antigravity's store,
  =~/.gemini/antigravity/conversation_summaries.db=, along with its custom title annotations in
  =~/.gemini/antigravity/annotations/= and JSONL transcripts in =~/.gemini/antigravity/brain/=.
- ~lispm-agents-send-region~ (=C-c a r=) puts the region, with where it is, into a running
  Antigravity's input.
- It sees what only Emacs knows: the selection, the files open and unsaved, Flymake's
  diagnostics, and LispM's tools and peer messaging, over MCP.  Each terminal gets a server of
  its own, reached through this package's bridge, =bin/emacs-mcp=, which
  =M-x lispm-antigravity-setup= registers once as Antigravity's MCP server ~emacs~.

Without ~agy~ on ~PATH~, Antigravity shows nowhere, and LispM Desktop's App Store greys it out
with the command configuring ~agy~ on ~PATH~.

* Installation

From LispM Desktop's App Store: AI Harness, Antigravity, Get.  Removing it there takes
Antigravity away from the editor at once; its sessions stay in Antigravity's store.

By hand, from a checkout, with lispm-agent's =lisp/= on the load path:

#+begin_src emacs-lisp
(add-to-list 'load-path "~/src/lispm-antigravity")
(require 'lispm-antigravity)
(keymap-global-set "C-c a" lispm-agents-map)
#+end_src

* Tests

make test compile LISPM_AGENT=../lispm-agent/lisp
